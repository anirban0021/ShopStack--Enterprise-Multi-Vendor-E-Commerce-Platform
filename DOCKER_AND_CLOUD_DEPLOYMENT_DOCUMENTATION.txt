5. CONTAINER IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------
A. Backend Dockerfile (`backend/Dockerfile`):
   - Stage 1 (Builder): maven:3.9.6-eclipse-temurin-21-alpine
     * Pre-downloads Maven dependencies using `mvn dependency:go-offline -B` for Docker layer caching.
     * Packages executable jar with `mvn clean package -DskipTests -B`.
   - Stage 2 (Runtime): eclipse-temurin:21-jre-alpine
     * JVM memory configuration: `-XX:+UseContainerSupport -XX:MaxRAMPercentage=75.0`
     * Built-in curl healthcheck querying `/api/products` every 30s.
     * Creates persistent upload directory `/app/uploads/products`.

B. Frontend Dockerfile (`frontend/Dockerfile` & `frontend/nginx.conf`):
   - Stage 1 (Builder): node:20-alpine
     * Installs dependencies via `npm install` and creates minified production build via `npm run build`.
   - Stage 2 (Runtime): nginx:alpine
     * Single-port unified reverse proxy on port 80.
     * SPA routing fallback `try_files $uri $uri/ /index.html;`.
     * Reverse proxies `/api/` -> `http://backend:8080/api/` with upstream header forwarding.
     * Reverse proxies `/uploads/` -> `http://backend:8080/uploads/`.
     * High-capacity upload limit `client_max_body_size 50M;`.
     * Gzip compression enabled for CSS, JS, JSON, and SVG assets.

C. Multi-Container Orchestration (`docker-compose.yml`):
   - Service `db`: postgres:16-alpine with healthcheck `pg_isready` and volume `shopstack_postgres_data`.
   - Service `backend`: depends_on `db` (condition: service_healthy), volume `shopstack_backend_uploads`.
   - Service `frontend`: depends_on `backend`, port `80:80`.
   - Bridge network: `shopstack-network`.
